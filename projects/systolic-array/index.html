4×4 INT8 Systolic Array

A matrix-multiply accelerator built as a 4×4 grid of INT8 multiply-accumulate units, verified with self-checking seeded random testbenches and a Python regression flow, and run on a DE2-115 FPGA over UART.

GitHub ↗

Stack

SystemVerilog · Python · Terasic DE2-115 (Cyclone IV E) · UART

What I did

  • Designed a matrix-multiply accelerator as a 4×4 systolic grid of INT8 multiply-accumulate units in SystemVerilog.
  • Verified it with self-checking, seeded random testbenches driven by a Python regression flow.
  • Ran the design on a DE2-115 FPGA, streaming operands and results over UART.
