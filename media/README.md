Drop images/videos into the matching project folder below. Name files
`1`, `2`, `3`, ... in the order you want them shown — any extension from
the supported list works, no HTML/JS edits needed. Refresh the page and
the "View Project" button appears automatically once a folder has at least
one file.

Supported extensions:
- Images: jpg, jpeg, png, webp, gif
- Videos: mp4, webm, mov

Folders:
- media/mech-keyboard/    -> STM32-Based Mechanical Keyboard
- media/seer/             -> SEER (Object & Temperature Detection Device)
- media/tof-scanner/      -> ToF Spatial Scanner
- media/marine-boat/      -> Marine Debris RC Boat

Example:
  media/tof-scanner/1.jpg
  media/tof-scanner/2.mp4
  media/tof-scanner/3.png
